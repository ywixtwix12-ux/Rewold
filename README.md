# Rewold

Редактор HTML и текстовых документов на Python + Tkinter.

Сейчас Rewold умеет:

* редактировать текст и HTML;
* автоматически закрывать HTML-теги;
* подсвечивать HTML-синтаксис;
* показывать Live Preview;
* проверять русскую орфографию;
* сохранять `.html`, `.txt` и `.md`;
* работать с контекстным меню по ПКМ.

Проект находится в разработке.

## Возможности

### HTML

Автозакрытие тегов:

```html
<p>
```

превращается в:

```html
<p></p>
```

Курсор остаётся между тегами:

```text
<p>|</p>
```

Для самозакрывающихся элементов (`br`, `img`, `input` и т. д.) закрывающий тег не добавляется.

### Подсветка

Подсвечиваются:

* теги;
* атрибуты;
* строки;
* комментарии;
* `DOCTYPE`.

### Live Preview

HTML отображается рядом с редактором.

Предпросмотр можно отключить через:

`Вид → Переключить предпросмотр`

Для него используется `tkinterweb`.

### Проверка орфографии

Для русских слов используется `pyspellchecker`.

Проверка выполняется после завершения ввода слова. Найденные подозрительные слова подчёркиваются.

Полную проверку можно запустить через контекстное меню.

### Контекстное меню

ПКМ по редактору открывает:

* Отменить;
* Повторить;
* Вырезать;
* Копировать;
* Вставить;
* Выделить всё;
* Проверить орфографию;
* Обновить предпросмотр.

## Установка

Требуется Python 3.10+.

Установить зависимости:

```bash
pip install tkinterweb pyspellchecker
```

Запустить:

```bash
python main.py
```

## Зависимости

| Библиотека       | Назначение              |
| ---------------- | ----------------------- |
| `tkinter`        | интерфейс               |
| `tkinterweb`     | Live Preview            |
| `pyspellchecker` | проверка орфографии     |
| `re`             | обработка HTML и текста |
